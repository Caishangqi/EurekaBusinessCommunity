# Restaurant 餐饮模块

Restaurant 是基于 Core 的可选内容模块，面向后续餐饮模拟玩法和附属扩展。

## 模块边界

Restaurant 依赖 Core，但与 Retail 互不依赖。餐厅菜单、餐饮烹饪方块、用餐订单和餐饮任务属于 Restaurant 自身的业务领域，不通过 Retail 商品目录混用实现。

## 与 Core 的契约关系

Restaurant 可以消费 Core 提供的：

- 稳定限定 ID 与公共数据模型；
- 要素注册与冻结只读视图；
- 顾客变体、行为任务和 Work Order 扩展契约；
- 服务端权威、持久化和生命周期框架。

## 当前开发状态

Restaurant 的首发内容、菜单模型、餐饮订单和发布条件由后续 Spec 规划。本页仅阐明模块架构边界。

附属模组若要实现餐饮兼容，应将兼容代码封装在独立适配层中，并在目标模组缺失时优雅禁用相关功能。
