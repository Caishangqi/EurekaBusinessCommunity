# 物品与方块概览

本目录汇总了 **EurekaBusiness** 模组注册的所有核心物品与方块，并按功能体系分类介绍：

## 模组分类目录

* [店铺空间与营业管理](Shop-Management-Blocks.md)：商店配置器 (`shop_configurator`)、店铺钥匙设备 (`key_device`) 与商店钥匙 (`shop_key`)。
* [收银台与结算设备](Cash-Register-and-Checkout.md)：收银台 (`cash_register`) 与收银台把手 (`cashier_handle`)。
* [陈列基座与价格牌](Pedestals-and-Price-Tags.md)：三种材质陈列基座 (`nomad_pedestal`, `deepslate_pedestal`, `stone_pedestal`)、价格牌模块 (`upgrade/price_tag`) 与升级模版 (`upgrade_template`)。
* [容器标签与标签配置器](Labels-and-Configurator.md)：标签配置器 (`label_configurator`)、空白标牌 (`blank_label`)、小费标签 (`tip_label`) 与退货标签 (`return_label`)。
* [价值容器与收益存储](Value-Containers.md)：价值容器 (`value_container`) 与 5 阶升级合成规则。
* [店铺装饰品](Decorations.md)：石像鬼雕像 (`gecho_gargoyle`) 与回响之号角 (`resounding_horn`)。

{% hint style="info" %}
每一个物品与方块的详细属性、使用方式、合成方式以及可配置参数均在各自页面中完整列出。
{% endhint %}
