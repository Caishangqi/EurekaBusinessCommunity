# EurekaBusiness (聪慧企业) 官方文档

![店铺实景全貌](../assets/shop_overview.png)

欢迎查阅 **EurekaBusiness** 官方文档。EurekaBusiness 是面向 Minecraft 1.21.1 / NeoForge 的多人合作模拟经营模组。

本站为玩家、店主、整合包作者以及模组附属开发者提供详细的玩法指引、物品与方块说明、配置参考与开发接口。

---

## 本文档适合谁？

本文档旨在提供全面且准确的模组信息：

* **生存模式玩家与店主**：了解如何从零圈定店铺、陈列商品、吸引顾客、进行结算并装饰店铺。
* **整合包作者**：了解如何在各功能项目下方查找配置格式（如商品目录与要素经济），调整参数与平衡性。
* **模组附属开发者**：查阅 API 架构、自定义要素注册契约、顾客变体扩展以及 AI 算法编写规范。

> [!NOTE]
> 本模组采用**服务端权威架构**。所有店铺状态、价格决策、交易结算与持久化数据均在服务端进行验证与记录，客户端仅负责输入交互与渲染呈现。

---

## 模组版本与运行环境

| 属性 | 规格 / 基线 |
| :--- | :--- |
| **游戏版本** | Minecraft Java Edition `1.21.1` |
| **模组加载器** | NeoForge `21.1.x` (推荐 `21.1.238`+) |
| **Java 版本** | Java 21 |
| **必需前置依赖** | `Fzzy Config` (`0.7.6+1.21+neoforge`), `Kotlin for Forge` (`5.4.0`) |
| **内容组织** | 包含基础平台 Core 与零售业务 Retail 模块 |
